# 応用実習1,2：作曲（京都精華大学 メディア表現学部・火曜／有村担当）

有村崚が担当する作曲の授業のカリキュラムと教材。
原稿の本体は `curriculum.md`（ここが唯一の正本。以前は ~/Desktop に置いていた）。
`build.py` がそれを読んで `../composition-site/` に特設サイトを生成する。
公開URL：https://intheblueshirt.com/composition/

## 授業の条件

- 2026年度 3Q・4Q、**火曜3〜4限**（90分×2コマ）、全14回
- 音楽表現専攻2年の必修。**受講者21名**（第一希望13／第二希望8）
- 学生のレベル差が大きい。譜面が読めない・キーの判別もできない学生もいる
- 作詞はやらない（メロとコードのみ。歌詞・言葉に関する内容は入れない）
- **この授業には既存の講義資料がない。このサイトがその代わりになる**

## カリキュラムの設計方針（決定済み）

- **各回のページは「ドリルN」と呼ぶ（「第N回」とは書かない）。** 授業のコマを指す「全14回」「今回」「次回」はそのまま
- **ドリルと授業の回は別物。** 全15ドリル／全14回。どのドリルを何回目の授業でやるかは一覧表の「授業」列。
  Phase 1（ドリル1・2）は授業1回目に1コマずつ（2026-09-28）。空いた1回はドリル11「寄り道コード」に使った（叩き台）。
  Phase 2（ドリル3・4）は授業2回目に1コマずつ（2026-09-29）。
- **3Q＝授業1〜7回目、4Q＝授業8〜14回目（各7コマ）。7回目と14回目はクオーター末課題の日**（2026-09-29、有村さん指定）。
  課題日は一覧表の下の「授業｜日付｜予定」の表に書く（ドリルではないので番号は振らない）。14回目はドリル15（発表・相互分析）の日
- **授業日**（学年暦 `大学関連/2026/事務/2026年度学年暦_教員配布用(202602更新版).pdf` の火曜・Q列①〜⑦）：
  3Q 10/6 10/13 10/20 10/27 11/10 11/17 11/24（11/3は補講日）／4Q 12/1 12/8 12/15 12/22 1/5 1/19 1/26（12/29一斉休業、1/12補講日）
- すべて移動ドの相対度数で捉える。表記は数字 1〜7 に統一し、音名・ドレミは使わない
- メロの各音を「キー度数/コード度数」の2軸で書く（例：Am の上のド＝「1/3」）
- 使える音をドリルごとに解禁する：1と2 → 3と5 → 6（ペンタ）→ 4 → 7 → テンション → ♭3/♭7
- コード進行はドリル1から「選ぶ」形で触らせ、ドリル4でペンタのメロに「付ける」、ドリル5・7で「組む」側に渡す
- 制作は全員 C キー＋DAW のスケールロック。最後に移調して「キー＝数字は同じで高さが変わる」を体感させる
- 毎回冒頭15分は「1度当て」でキーがわからない層をフォローする
- 各回に基本課題と発展課題を用意してレベル差を吸収する
- 1限目＝聴く・歌う、2限目＝打ち込む・出す。1限目の終わりに全員が歌える状態を作る
- **「標準の流れ」（1回の時間配分表）は削除した。進めるところまで進む方針**（2026-09-30、有村さん指定）。
  build.py はこの節が無くても動く。各ドリルの「時間配分」行は残っているが目安でしかない

## 決定の経緯（変更するときに注意）

- **1度と2度は同時に解禁する。** 安定と不安定は2音ないと作れないため。
  1音しか使えない回を置くと「落ち着く音」を体験させられず、狙いと手段が噛み合わない。
  （2026-09-27に変更。以前は 1 → 5 → 3 → 2 の順で、ドリル1〜2は1度だけだった）
- **順次進行を跳躍より先に教える。** 1 → 5 → 3 の順だと Phase 1 で作れるのがアルペジオだけになり、
  「ポップスのコツ」の「基本は順次進行、跳躍はここぞで」と逆の順序を教えることになっていた
- **ドリル2で3と5を同時に解禁する（1 2 3 5）**（2026-09-30、有村さん指定）。1・2・3だけの見本曲が日本の曲にほぼ無く、
  1・2・3・5なら知っている例が多いため。着地も1（完結）・3（余韻）・5（続く）の3択になる。
  上の「順次が先」を崩さないよう、ドリル2の課題に「跳躍は8小節で1〜2回まで、跳んだら順次で戻る」を入れ、
  コツ「基本は順次進行、跳躍はここぞ」「跳躍したら戻れ」の導入もドリル2に前倒しした。
  見本はメリーさんのひつじ（順次進行）とようかい体操第一（跳躍）。
  あわせて ドリル3＝ペンタ（旧ドリル4のヨナ抜き）、ドリル4＝ペンタのメロにコードを付ける（新規）にした。
  以前は ドリル2＝1 2 3、ドリル3＝5と跳躍、ドリル4＝ヨナ抜き
- **Phase 1 の進行は IVM7-IIIm7-IIm7-I**（2026-09-28、有村さん指定）。IIIm7 の上で1が♭6（アボイド）、2が7になり、
  1と2の使い分けがそのまま課題になる。V を含む進行（I-VIm-IV-V など）はピアノロールのプルダウン候補として残す
- **4on5（IV/V）は初期に使わない。** 初学者には「ドミナント＝V」の像がぼやけ、
  ドを IV の5th と読むか V の11th と読むかで混乱するため。ドリル12で種明かしする
- **中間制作はドリル6（授業4回目）。課題は「ペンタ＋ダイアトニックで曲を作る」**（2026-09-29、有村さん指定）。
  ペンタ（ドリル3）・ペンタのメロへのコード付け（ドリル4）・ダイアトニックと機能（ドリル5）の後に置く。続くドリル7（終止とリハモ）で
  「自分のメロにコードを付け直す」につなげる。以前はヨナ抜きの直後（旧ドリル5）だった
- ブルーノート（♭3/♭7）はドリル13のモチーフ展開と抱き合わせ。♭VIM7・♭VII7 もここで出す（♭3・♭7 がコードトーン）
- 「ポップスのコツ」はコード・音選び・形・リズムの4観点。
  言葉の観点は作詞をやらないので削除した。構成の観点も外した（2026-09-28）
- **コツのページ全体の鉄則は「繰り返さないと意味不明、繰り返しすぎるとおもんない」。** 冒頭文の下に大きく出す（以前はリズムの節の頭だった）
- **コードの観点は「普通のコードと変なコードを区別する」「ダイアトニックコードをグループ分けする」と、覚えるべきコードの tier 表。**
  どちらもコツのページの一番上に出す。tier 表にあるのが普通のコード、それ以外は変なコード、くらいの扱い。
  sus4 以外は全部4和音で書く。tier1＝IM7〜VIIm7-5 と Isus4・IVsus4・Vsus4／tier2＝III7・IVm7（次に引っ張る系と短調から借りる系から1つずつ）／
  tier3＝VI7 II7 I7 Vm7 #IVm7-5 #Idim7 #Vdim7 ♭II7（次に引っ張る系）・♭VIM7 ♭VII7（短調から借りる系）。
  ページには系統のラベルは出さない（「引っ張る」「借りる」は外した）。tier1 はグループ分けのコツの3グループで色分けする。
  #Vdim と #Idim は III7・VI7 の根音抜きとほぼ同じ音で、行き先も同じ。
  **Phase 1〜3 にはダイアトニック外のコードを出さない。Phase 4 以降は Phase が進むごとに1個以上を新しく出す**（2026-09-28、有村さん指定）。
  新しく書く本文にも「引っ張る」「借りる」は使わない。叩き台の割り当て：ドリル8 IVm7／ドリル9 III7／ドリル11 VI7・II7・I7・Vm7・#Idim7・#Vdim7／ドリル12 ♭II7・#IVm7-5／ドリル13 ♭VIM7・♭VII7。
  各ドリルの「新コード」行に書く
- **「ざっくり音楽理論史」（history/）は原典なしの新規教材**（2026-09-29）。
  大学関連フォルダに歴史の資料が無いことを確認済み。クラシックとバークリーの2系譜＋合流ノード「この授業」の構成
  （「2つの系譜のつながり」の定義行の節はイランと消された。2026-09-29）
- **「音楽理論ロードマップ」の原典は、DTM初級の講義スライド**
  `~/Dropbox/大学関連/2026/DTM初級/授業資料/DTM初級20260622.pptx`
  の p.20-61「何もわからないい人用の音楽理論ロードマップ」。
  **これは1Q/2QのDTM初級（月曜）の資料で、この授業のものではない。**
  内容は転用してよいが、出どころを取り違えないこと。
  4段階（トーナリティ→インターバル→メジャースケール→ダイアトニックコード）と、
  「音楽理論＝いいかんじの音楽あるある」「根幹＝中心からの距離で安定/不安定をコントロールする体系」
  「不安定＝安定したいという欲望」は原典の言葉。**勝手に段階を作り直さないこと。**
  授業の回への対応は各段階の末尾に小さく添えるだけにする
- **和音は135積みにしない。** ベースにルート、上は転回形の3声（4和音はルート抜きの3・5・7）。詳細は README の「和音のボイシング」（2026-09-28）
- 評価の比重は **授業参加度50／中間制作10／最終制作20／学習理解度(到達目標達成度)20**（2026-09-30、有村さん指定。
  以前の 課題40/中間20/最終30/相互分析10 は仮置きだった）

## 文章の方針（学生が読む文すべて）

**「ポエムいらない、核だけ」。** 主張・事実・指示だけを短く言い切る。
説明のための描写、資料やページについての説明、何でも「ラベル：本文」に並べる書き方は「AI臭い」「きもい」と突き返された（2026-09-28）。
気取った言い回し・擬人化も同じ（「この授業もここにいる」→「この授業もこれ」に直された。2026-09-29）。
見本は有村さん自身の文：
- 「ポップスとは、真ん中（トーナルセンター）からの距離でデザインする音楽。だから、キーの理解が全ての出発点になる。」
- 「ポップスの作曲コツ集。あくまでコツであってルールではない。」

名詞止めでよい。書き直すときは元より短くする。有村さんが書いた見出し・文は言い換えない。
