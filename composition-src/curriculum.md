# 応用実習1,2：作曲 全14回カリキュラム（移動ド・度数で作る）

京都精華大学 メディア表現学部／火曜・有村崚担当

Sep 27, 2026 · @Ryo Arimura

## 授業の狙いと前提

メロの全部の音を、キーから何度か・コードから何度かで見て作曲する授業。

**到達目標**

- 曲を聴いてキー（1度）がわかる
    - 毎回、冒頭15分で「1度当て」
- メジャースケールとダイアトニックコードを度数で説明できる
- メロの各音を「キー度数/コード度数」で書き、狙って選べる
- ダイアトニックコードを機能で並べて4小節の進行を作れる
- 8〜16小節の曲を作れる

**表記ルール**

- 音名・ドレミは使わず、移動ドの1〜7で書く
- コード度数はR・3・5・7・9など
- 記入例：Amの上のド＝「1/3」、Gの上のソ＝「5/R」、Fの上のド＝「1/5」

## 標準の流れ（90分×2コマ）

**1限目（90分）聴く・歌う**

| 時間 | パート | 内容 |
| --- | --- | --- |
| 0:00–0:15 | 耳トレ | 1度当て。落ち着く音をハミングして鍵盤で探す |
| 0:15–0:45 | 講義 | 今日の解禁音と度数 |
| 0:45–1:10 | 分析 | 曲から今日の音を度数で書き取る |
| 1:10–1:30 | 制作① | 歌って作る。歌えるまで打ち込み禁止 |

**2限目（90分）打ち込む・出す**

| 時間 | パート | 内容 |
| --- | --- | --- |
| 0:00–0:35 | 制作② | 歌ったメロを打ち込む |
| 0:35–0:45 | 中間チェック | 度数シートを見て回り、ルール違反を直す |
| 0:45–1:05 | 制作③ | 直し＋移調。度数が変わらないか確認 |
| 1:05–1:25 | 発表 | 数人指名。度数シートと一緒に聴く |
| 1:25–1:30 | 宿題 | 次回の解禁音を予告 |

機材トラブルはコマ間の休憩で片付ける。1限目で歌えなかった人は2限目の頭に個別で見る。

## 各回の詳細

### Phase 1：安定と不安定（第1〜2回）

#### 第1回　1と2、帰る音と離れる音

- **狙い**：1度を耳で見つけ、2から1に帰る安定を覚える
- **講義**：移動ドと数字表記。1-2-1は刺繍音。1はIの上でR、VImの上で3、IIm7の上で7、IVの上で5、Vの上で4（11th）
- **分析**：1音連打のフック、2音だけのメロ
- **伴奏**：I-IV-VIm-IV。I-VIm-IIm7-IV、I-VIm-IV-V でも可
- **基本課題**：30分は1度だけで8小節。次に2を足して作り直し、違いを言う
- **発展課題**：同じメロで進行を3種類替え、好みをコード度数で説明する
- **体験**：Vの上で1を伸ばして2へ。落ち着く瞬間を全員で聴く

#### 第2回　3を足す、順次進行と着地

- **狙い**：順次進行でつなぎ、終わる音で印象を変える
- **講義**：1-2-3は経過音。3はIの上で3、IIImの上でR、VImの上で5、IVの上で7（maj7）。IIImの上の1は♭6でアボイド。1着地は完結、3着地は余韻
- **分析**：順次進行のメロ、主和音アルペジオ型のメロ
- **伴奏**：I-IIIm-IV-V
- **基本課題**：1着地と3着地の2バージョン
- **発展課題**：2小節で問い（3着地）、2小節で答え（1着地）

### Phase 2：ペンタで歌にする（第3〜5回）

#### 第3回　5と跳躍

- **狙い**：跳躍を使い、歌える音域まで広げる
- **講義**：5はIの上で5、Vの上でR、IVの上で9、VImの上で7。跳躍したら逆向きに順次で戻る
- **分析**：1と5だけのメロ、ベースライン
- **伴奏**：I-VIm-IV-V
- **基本課題**：5度跳躍は1か所だけ。その後は順次で埋める
- **発展課題**：下の5も使い、1オクターブ＋2〜3度まで広げる

#### 第4回　ヨナ抜き

- **狙い**：5音（1 2 3 5 6）だけで歌う
- **講義**：6はIの上で6、IVの上で3、IImの上で5、VImの上でR。4と7を抜くと半音が消え、ぶつかりにくい
- **分析**：J-POP・民謡のヨナ抜きメロ
- **伴奏**：ダイアトニック内で自由
- **基本課題**：ヨナ抜きで8小節
- **発展課題**：ニロ抜き（6 1 2 3 5）でVIm中心にし、短調に寄せる

#### 第5回　中間制作・発表

- **時間配分**：1限目は制作90分。2限目は全員発表60分（1人3分弱）＋講評30分
- **課題**：ヨナ抜きで8小節×2のAB構成。Aは1着地、Bは3か5着地で次へつなぐ
- **提出物**：音源と度数シート（全音のキー度数/コード度数）
- **フォロー**：1度当てが不安な人は個別確認

### Phase 3：コードを作る（第6〜7回）

#### 第6回　ダイアトニックと機能

- **狙い**：機能で進行を組む
- **講義**：ダイアトニックコードは7つ（I IIm IIIm IV V VIm VIIm-5）。トニック＝I VIm IIIm、サブドミナント＝IV IIm、ドミナント＝V VIIm-5、流れはT→S→D→T
- **分析**：第1〜5回の進行を機能で読み直す
- **伴奏**：自分で4小節組む
- **基本課題**：T-S-D-Tの4小節進行を3つ作り、同じメロで聴き比べる
- **発展課題**：VIm始まりで短調に寄せ、聴こえ方の変化をメモ

#### 第7回　終止とリハモ

- **狙い**：終止を選び、メロにコードを付け直す
- **講義**：全終止（V-I）、変格終止（IV-I）、偽終止（V-VIm）。代理コード（I↔VIm、IV↔IIm）とリハモの手順
- **分析**：終止だけ違う同じメロの聴き比べ
- **伴奏**：自分で組む
- **基本課題**：第5回のメロに自分の進行を付け直す
- **発展課題**：同じメロを3通りリハモし、各音のコード度数の変化を書く

### Phase 4：危ない音（第8〜10回）

#### 第8回　4度とアボイド

- **狙い**：キーで安全な音も、コード次第で危ない
- **講義**：4度はIで4（アボイド）、IVでR、IImで3、V7で7、VImで♭6（アボイド）
- **分析**：4→3で解決するメロ
- **伴奏**：IV中心（IV-I、IV-V など）
- **基本課題**：4度はIVとIImの上だけで使う
- **発展課題**：Isus4→Iで4を3へ解決

#### 第9回　7度と導音

- **狙い**：1に帰りたがる7を使う
- **講義**：7度はVで3、IIImで5、Iでmaj7。V7の4と7（トライトーン）は3と1へ解決
- **分析**：サビ終わりの7→1
- **伴奏**：V7多め
- **基本課題**：V7の小節の7を、次のIで1へ解決
- **発展課題**：7→6と下げ、1へ行かない

#### 第10回　全7音＋強拍コードトーン・ルール

- **狙い**：全7音をコードを見て選ぶ
- **講義**：強拍はコードトーン、弱拍は非和声音。非和声音は経過音、刺繍音、倚音、逸音、先取音、掛留音
- **分析**：実曲の強拍を全部コード度数で書き出す
- **伴奏**：自由
- **基本課題**：強拍が全部コードトーンの8小節
- **発展課題**：倚音（強拍の非和声音→解決）を1か所入れる

### Phase 5：設計する・意図して外す（第11〜14回）

#### 第11回　テンション狙い

- **狙い**：同じキー度数でも、コード度数で色を選べる
- **講義**：強拍に9thやmaj7（Iの上の2、IVの上の3、Iの上の7など）。4on5（IV/V）＝Vの上で1度を使う技
- **分析**：サビ頭がテンションの曲
- **伴奏**：自由＋IV/V
- **基本課題**：強拍に9thを2か所以上
- **発展課題**：メロそのままでリハモ。コード度数の変化を記録

#### 第12回　モチーフ展開＋ブルーノート

- **狙い**：短いモチーフを1曲分に伸ばす
- **講義**：モチーフ展開＝反復、度数ごとの平行移動（ゼクエンツ）、リズム変形、反行。ブルーノート＝♭3と♭7
- **分析**：1つのモチーフで押し切る曲
- **基本課題**：2小節のモチーフを反復と平行移動で8小節に
- **発展課題**：♭3か♭7を1か所入れ、コード度数を書く

#### 第13回　最終制作

- **時間配分**：1限目は制作90分。2限目は制作60分＋個別面談30分（制作と並行、1人数分ずつ）
- **課題**：16小節以上。先に進行を決め、度数設計シートを埋めてから作る
- **条件**：強拍にテンション1か所以上。狙った着地を書く

#### 第14回　発表・相互分析

- **時間配分**：2コマとも発表。1限目は前半、2限目は後半＋振り返り。21名なら1人8分
- **形式**：作品を流す→聴く側が度数シートなしで1度と着地音を当てる→作者が狙いを話す
- **振り返り**：第1回の1と2だけの曲と聴き比べ

## 音楽理論ロードマップ

音楽理論＝いいかんじの音楽あるある。先人がうまくいった手法に名前がついてるだけ。

参考：五度圏（SoundQuest） https://soundquest.jp/quest/prerequisite/co5th/

### 段階1　トーナリティ（キーの認識）の感覚を理解する

- ポップスとは真ん中（トーナルセンター）からの距離でデザインする音楽
- だからキーの理解が全ての出発点になる

- **対応回**：第1回

### 段階2　音のインターバルの数え方を覚える

- 距離を測れないと話ができない

| インターバル | 中心からの半音 | メジャースケール |
| --- | --- | --- |
| 1度 | 0 | ○ |
| 短2度 | 1 |  |
| 長2度 | 2 | ○ |
| 短3度 | 3 |  |
| 長3度 | 4 | ○ |
| 完全4度 | 5 | ○ |
| 増4度／減5度 | 6 |  |
| 完全5度 | 7 | ○ |
| 増5度／短6度 | 8 |  |
| 長6度 | 9 | ○ |
| 短7度 | 10 |  |
| 長7度 | 11 | ○ |
| 完全8度（オク上） | 12 | ○ |

- **対応回**：第1回・第2回

### 段階3　メジャースケールを覚える（いけたらマイナースケールも）

- 12音から使う音を抜き出したのがスケール
- メジャースケールは全全半全全全半
- メロもベースもこの7音の番号で管理する

| 度数 | 安定度 | キャラ |
| --- | --- | --- |
| 1度 | 安定 | 終止感。帰ってくる場所 |
| 2度 | やや不安定 |  |
| 3度 | そこそこ安定 |  |
| 4度 | やや不安定 |  |
| 5度 | そこそこ安定 | 1度に行きたくなる |
| 6度 | そこそこ安定 |  |
| 7度 | やや不安定 | まあまあ1度に行きたくなる |

- 不安定＝安定したいという欲望

- **対応回**：第2回・第3回・第4回

### 段階4　ダイアトニックコードを覚える（4和音）

- スケールの音を積んだコード
- これも番号で覚える

- **対応回**：第6回・第7回

### 補足　繰り返しが超重要

- 音楽とは"繰り返しの入れ子構造"である

- **対応回**：第12回

## 評価とワークシート

評価は「度数で説明できるか」。好みやセンスは問わない。

| 項目 | 比重 | 見るところ |
| --- | --- | --- |
| 毎回の課題提出 | 40% | 解禁音のルールを守れてるか |
| 中間制作（第5回） | 20% | 着地の狙いとシートの正確さ |
| 最終制作（第13〜14回） | 30% | 狙いと実際の音が合ってるか |
| 相互分析への参加 | 10% | 人の曲を度数で説明できるか |

**度数シートの段階**

- 第1回前半：キー度数だけ
- 第1回後半〜：キー度数/コード度数（例：1/3）
- 第6回〜：コードの機能（T・S・D）も書く
- 第10回〜：強拍に印、非和声音の種類も書く

**1度当ての運用**

- 毎回2〜3曲、ジャンルを変えて出す
- 第5回までに全員が1度を歌える状態に。できない人は中間制作で個別に見る
