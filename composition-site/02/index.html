ドリル2　3と5を足す、着地と跳躍

今日覚える

  • 1度は安定する
  • 2度はやや不安定
  • 3度は結構安定
  • 5度も結構安定で、1度に行きやすい

例を聴く

メリーさんのひつじ（順次進行）

  • ABAC構造と捉える
    • A　メリーさんのひつじ
    • B　ひつじ　ひつじ
    • A　メリーさんのひつじ
    • C　かわいいね
  • {ABBB}{ABCC}
    • A　メリーさんの
    • B　ひつじ
    • B'　ひつじ(同リズム異メロ)
    • B''　ひつじ(同リズム異メロ)
    • A　メリーさんの
    • B　ひつじ
    • C　かわいいね(新メロでエンディング)

1〜4小節：A　B　B'　B''

5〜8小節：A　B　C

  • 順次進行でメロが構成されている
  • 4小節末尾は5度(結構安定だが、終わってはない)
  • 8小節末尾は1度(ど安定、終わった感)
  • 繰り返し構造の巧みさ

ヨーでる ヨーでる ヨーでる ヨーでる／ようかいでるけん でられんけん（×2）

  • 同音連打(3度)
  • 1度と5度の跳躍
  • 4小節ケツで1度に落とす前に一旦2でスパイス
  • ABAB構造

やってみる

  • 基本
    • 1で締めると終わった感
    • 1,3,5は無邪気に使っていい
      • 伸ばす、連打するも可
    • 2は使い所を見極める
      • 不安定にするぞ、と思って繰り出す
    • 跳躍はやりすぎない
  • 発展
    • 繰り返し構造を意識する
      • どう繰り返し、どう変化させるかを名曲から学ぶ
