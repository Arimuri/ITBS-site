コードのつながり

ルートの動き

  • 4度上（＝5度下）が一番強い。V7-Imaj7、IIm7-V7、VI7-IIm7
  • 次が2度（IV-V、♭VII-I）、その次が3度（I-VIm、I-IIIm）
  • 増4度が一番遠い
  • 3度の動きは弱いぶん、なめらか

共通音

  • 共通音が多いほど、つながりはなめらか
  • I と VIm は 1・3、I と IIIm は 3・5 が共通。4和音なら3音が共通
  • 共通音ゼロのつながり（I-♭II など）は場面転換になる

1音だけ動かす

  • 三和音の2音を残して1音だけ動かすと、キーの外のコードにもなめらかに行ける
動かす音例
3を半音下げるI → Im
ルートを半音下げるI → IIIm
5を全音上げるI → VIm
  • 重ねると遠くへ行ける。I → Im → ♭VI は、3を半音下げ、次に5を半音上げた形
  • 交互に重ねると、長3度ずつ・短3度ずつ遠いコードへ進める

やってみる

  • I-VIm-IV-V のルートの動きを書き出す
  • 3度の動き1つを4度上の動きに替えて聴き比べる

ボイシング

  • ベースがルートを弾く。上はルートを抜いて3音（4和音なら3・5・7）
  • 1・3・5 で下から積まない
  • 低いほど広く。上の一番下はベースから5度以上離す。真ん中のオクターブより下では2度・3度を重ねない
帯域担当
〜80Hzキックとサブベース。和音は置かない
80〜200Hzベース
200〜2500Hz和音
2.5〜6kHz歌・リード
6kHz〜ハイハット
  • 省くなら 5 → R（ベースが弾くとき）→ 11・13 の順。3と7は最後まで残す
  • ルートを抜いた形は2種類。3が一番下だとコードの質がはっきり、7が一番下だと浮く。下の2音をオクターブ上げると入れ替わる
  • IIm7-V7-Imaj7 は「3が下」→「7が下」→「3が下」にすると、手がほとんど動かない
積み方作り方
密集1オクターブの中に積む
ドロップ2密集の上から2番目を1オクターブ下げる
4度積み4度ずつ積む
ルートレスルートを抜き、3・7・テンションで組む
  • V7 の上に別の三和音を乗せると、テンションがまとめて鳴る。V7-Imaj7 なら VI の三和音（9・#11・13）、V7-Im7 なら ♭III の三和音（♭13・R・#9）

やってみる

  • IIm7-V7-Imaj7 を「3が下」「7が下」「3が下」で弾く

ボイスリーディング

  • 3と7（ガイドトーン）が半音か同じ音でつながると、進行が流れる
  • IIm7-V7-Imaj7 のガイドトーン（キー度数/コード度数）
    • 1/7 → 7/3 → 7/7
    • 4/3 → 4/7 → 3/3
  • 共通音は同じ高さで保つ
  • 外声（ベースとトップ）は反対方向に動かす
  • 並行5度・8度は外声だけ避ける
  • 声部は交差させない
  • ♭II7 は V7 の3と7が入れ替わった形。IIm7-♭II7-Imaj7 でベースが半音で下りる

予想と外し

  • 予想どおりすぎると退屈、外れすぎると意味不明。気持ちいいのはその間
  • V7 の次は Imaj7 が一番の予想。VIm7（偽終止）と ♭VImaj7 は少し外れる。♭IImaj7 は大きく外れる
  • 外す前に予想を作る。同じ流れを2回聴かせて、3回目の1か所だけ変える
  • 外したら半音で戻る
  • サビは予想どおりに。外すのはサビ前とブリッジ

定番は1か所だけ変える

  • 定番進行をそのまま使うと既視感が出る
  • テンションを足しても転回しても、ルートの動きが同じなら印象は同じ
  • ルートを1か所替えると別物になる
  • 狙いが聴き手に読めると効かない。「盛り上げたいから半音上行」「緊張させたいから dim」は読まれる

やってみる

  • 4小節の進行を3回聴かせ、4回目の1コードだけを外す

緊張の設計

  • 緊張を上げる手段は3つ。機能（T→S→D）、テンション、予想外のつながり
  • セクションごとに緊張の形が違う
セクション緊張の形
イントロ低いまま
Aメロ低く始めて少しずつ上げる
Bメロ一気に上げて、サビの直前で最大
サビ高いまま保ち、最後から2番目で山、最後で着地
落ちサビ・ブリッジ上げ切ってから着地
アウトロ下げていく
  • サビの最後は着地させる。V で終わると締まらない
  • 4小節・8小節でまとめると座りがいい

リハモの置き換え

  • 進行の1か所を置き換えるだけで色が変わる。置き換えは5種類
置き換えI-VIm-IV-V に入れた例
次のコードに4度上で進む X7I-I7-IV-V
次のコードの半音上の7thI-♭V7-IV-V
次のコードの半音下の dim7I-VIm-#IVdim7-V
IV を IVm7 にI-VIm-IVm7-V
♭VImaj7 にI-♭VImaj7-IV-V
  • 4コードに1か所まで。最初と最後のコードは替えない
  • 毎回は替えない。くり返しの2回目か4回目だけ

2回目のサビ

  • 同じ進行の1コードだけを替える。替え先は ♭IIImaj7・IIIm7・VIm7・IIm7・♭VImaj7・♭VII7
  • 同じコードを並べ替えて、Aメロとサビを作る

やってみる

  • 自分の進行に置き換えを1か所だけ入れ、2回目だけで鳴らす

関連：ドリル5・ドリル11・ドリル12・ドリル13

テンションの選び方

  • テンションは、コードが乗っているスケールで決まる
コードスケール使えるテンションアボイド
Imaj7イオニアン9・1311（キー度数4）
IIm7ドリアン9・11—
IIIm7フリジアン11♭9（キー度数4）・♭13（キー度数1）
IVmaj7リディアン9・#11・13—
V7ミクソリディアン9・1311（キー度数1）
VIm7エオリアン9・11♭13（キー度数4）
VIIm7-5ロクリアン11・♭13♭9（キー度数1）
  • 短調の V7 は ♭9・♭13
  • 足す順番は 7th → 9th → 11th・13th → ♭9・#9・#11・♭13。♭9 から先はドミナントだけ
  • 9th が一番安全
  • メジャー系の11th は3とぶつかる。#11 にする。マイナー系の11th はそのまま使える
  • テンポが速いほど減らす。140 BPM を超えたら 9th まで
  • 足すのは1音。その音をトップに置く
  • 全部のコードには足さない

やってみる

  • 4小節の進行の各コードに1音だけテンションを足し、トップに置く

関連：ドリル7・ドリル12

ベースライン

  • 拍頭はルートか5。弱拍で3・7・半音のアプローチ
  • 小節の最後で次のルートに寄る。半音下、半音上、または次のルートの5から

ルート

ルートと5

ウォーキング

  • ウォーキングは、1拍目にルート、4拍目に次のルートの半音隣
  • キックとベースは同じ位置に揃える。ベースが伸びている途中でキックが来たら、切って打ち直す
  • 低い正弦波のサブはルートで止めておく。動きはその上のベースで出す

メロディの展開

  • モチーフは「リズム」と「コードトーンかどうか」で覚える。コードが変わったら音は選び直す
  • 展開の順番
段階やること
1そのまま2回
2平行移動・反行
3短く切ってくり返す・細かくする
4一番高い音を出す
5長く伸ばして着地

1〜2小節はそのまま、3小節は2度上へ平行移動、4小節は反行、5〜6小節は短く切って細かく、7小節で一番高い音、8小節で伸ばして1に着地。

  • 2度で進んでいる間は、同じ方向に続けると自然。大きく跳んだら、反対方向へ2度で戻る
  • 小節の最後の音を次のコードの音の半音隣に置くと、次の小節に吸い込まれる
  • 飾りの音は、上からなら全音、下からなら半音

関連：ドリル8・ドリル9
