心構え

マインド

  • 自分の作った曲が一番最高
    • 自分が作った曲が素晴らしい理由は、自分が作っていて、他の人には作れないから
      • 他人は自分より良くできた曲を作れるかもしれないが、自作曲は自分からしか生まれない
      • 自作曲をクオリティに関わらず愛することが継続のコツ
  • 技術面(歌、楽器、作編曲の技巧)を自分の曲の良さの拠り所にすると、競争になり大変
    • 上には上がいるので、競争は一生終わらない
      • 勝ち負けのみをモチベーションにすると、勝てなくなった時にきつい
        • 他人との比較で燃えるのも良いが、自分の成長を楽しむことも覚えよう
        • 勝ち負けを意識すべき時と、そうでない時を使い分けよう
      • 最近はネットのおかげで、無限に上手い人情報が飛び込んでくる
        • 負けた、とかは思う必要がない、上手い人はぜひ参考にしよう

習慣

  • 自分が好きなものは何かを頑張って捉える
    • いっぱい音楽を聴いて、リストを作ることを薦める
  • とにかくたくさん曲を作る
    • 音楽はプレイ時間がとにかく重要
    • 大抵の曲はゴミだが、気にしてはいけない
      • 短い曲でもいい、良くなくてもいい、たくさん作る
  • 作った曲を人に聴かせる習慣をつける
    • できるなら明日からやる
      • いい曲ができたら〜とか言うのは絶対にダメ、そんな日は来ない
    • 友達でもいいし、親でもいいし、おれでもいいし、ネットにあげてもいい
      • 自作曲を人に聴かれるという行為の心理障壁を一日も早くゼロにする

上記の習慣が出来次第、課題以外の作品を作って発表してみよう！

認知

  • 聴き取れないものは作れない
    • 聴き取るより作る方が100倍難しい
      • 聴き取れないものは(まぐれを除いて)ほぼ作れない
      • 聴き取る訓練を日常的にやっているやつとそうでないやつの間にはすごい差が出る
    • 意識して要素を聞きとる、やる気があればDAWでの音色も含めたコピーを習慣付ける

認知を高めるための習慣

  1. BPMを把握する　全員できる、絶対やる
    • BPMカウンター(ブラウザ)：BPMカウンター
  2. メインメロディを聴き取る　全員できる、絶対やる
  3. キーを把握する　要訓練
  4. リズム楽器(非音程楽器)を聴き取る
  5. リズムパターンを把握する
    • キック/スネア/ハイハット/その他　機能を分解して認知する
    • ハネ具合を認知する
    • 音色を認知する
  6. 音程のある楽器を聴き取る：キーの把握が肝要！なんとか身につけよう
    • 登場する楽器/音色を把握する
    • 単音楽器を聴き取る
    • 和音を聴き取る

音楽理論学習

何もわからない人のための音楽理論ロードマップ

真面目にいくなら、マナーとして以下4項目は必修(無視して我が道を行きたい人は止めはしない)。1の感覚さえ養えられれば、2〜4は1日で全て覚えられる程度の分量しかないので、これくらいは最低限頑張ってほしい。とにかく1をどうにかしよう

  1. トーナリティ(キーの認識)の感覚を理解する
    • ここが一番重要、中心を認識したり、認識させたりする感覚を養う
    • ”キーの音がわかる”とは
      • 移動ドでメロディを認識できる
      • Iの和音がなった時にトニックだと思える
    • 言葉を丸暗記しても意味ない、感覚を覚える
    • 自転車乗るみたいなもん、できればなんてことはないが、できないと意味不明
  2. 音のインターバルの数え方を覚える
    • 中心が決まれば、相手は12種類しかない、12個に名前がついているだけ、暗記
  3. メジャースケール＆マイナースケールを覚える
    • とりあえず２種類(最悪メジャースケールだけでも)を覚えよう
  4. ダイアトニックコードを覚える(4和音)
    • スケールの下にコードは作られる、メジャーダイアトニックは7つしかない

注意点

  • 音楽理論は音楽のごく一部分だけをカバーしている
    • (西洋音楽の)既存の音楽を説明したり、アイディアを転用するためのもの
    • 音楽理論で説明されない音色の部分の重要性は、思ったよりも大きいと思ってください

機材

心構え：持っているものでなんとかする。学生のお金は有限なので取捨選択を慎重に！

  • 機材：コントローラの優先度を下げ、まずは再生&録音環境を整えよう
  • モニター(音を聴く装置)：最初は基準を作るのが大事、同じ機種をなるべく長く使おう
    • ヘッドホン：コロコロ変えずに、まともなやつを3年くらい使い倒す
      • 最悪なんでもいいから、使い倒して基準にする
      • そのうちぶっ壊れるので、買い直せるやつの方が望ましい
      • 金に余裕があれば以下がおすすめ（選定理由：まともな音／密閉(RECで使える)／入手性の高さ／ユーザーの多さ）
        • 3万円だせる：audio technica ATH-M70x (or 60x)／YAMAHA HPH-MT8／SONY MDR-M1ST
        • 2万円だせる：audio technica ATH-M50x or 40x／SONY MDR-7506／SHURE SRH440A-A／YAMAHA HPH-MT5
        • 1万円以下の予算：手持ちのものでなんとかやりくりしつつ、1万円貯めることを勧めます
    • スピーカー：自宅環境次第
  • オーディオインターフェース
  • Midi鍵盤
  • 音源
    • シンセ：ソフトならあまり金がかからない
      • ファーストシンセを決める：徹底的に使う
      • 理由がなければウェーブテーブル方式の物を選ぼう。好きなシンセがあるならそれでOK
        • vital：無料で、機能的にも全く問題がない。ウェーブテーブルシンセのファーストチョイスにおすすめ
        • Serum2：有料のものがいいなら、こだわりがなければserumを勧める
        • その他はご自由に
    • 生楽器ライブラリ：課金が物を言う、学生は結構大変
      • 最初はlogic付属で頑張ってみる
      • 総合音源を1つ持って耐え忍ぶ（Kontakt派閥/Musio/その他）
      • バンド用：ドラム/ベース音源
      • オケ系：簡単にそれっぽくなるvsむずいが追い込める系
    • サンプル集
      • Splice：金に余裕があるならぜひ
