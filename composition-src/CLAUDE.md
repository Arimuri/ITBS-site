## 授業の条件

- 2026年度 3Q・4Q、**火曜3〜4限**（90分×2コマ）、全14回
- 音楽表現専攻2年の必修。**受講者21名**（第一希望13／第二希望8）

- 作詞はやらない（メロとコードのみ。歌詞・言葉に関する内容は入れない）

## カリキュラムの設計方針（決定済み）

- **各回のページは「ドリルN」と呼ぶ（「第N回」とは書かない）。** 授業のコマを指す「全14回」「今回」「次回」はそのまま
- すべて移動ドの相対度数で捉える。表記は数字 1〜7 に統一し、音名・ドレミは使わない
- メロの各音を「キー度数/コード度数」の2軸で書く（例：Am の上のド＝「1/3」）
- 使える音を1回ずつ解禁する：1と2 → 3 → 5 → 6（ヨナ抜き）→ 4 → 7 → テンション → ♭3/♭7
- コード進行はドリル1から「選ぶ」形で触らせ、ドリル6〜7で「組む」側に渡す
- 制作は全員 C キー＋DAW のスケールロック。最後に移調して「キー＝数字は同じで高さが変わる」を体感させる
- 毎回冒頭15分は「1度当て」でキーがわからない層をフォローする
- 各回に基本課題と発展課題を用意してレベル差を吸収する
- 1限目＝聴く・歌う、2限目＝打ち込む・出す。1限目の終わりに全員が歌える状態を作る

## 決定の経緯（変更するときに注意）

- **1度と2度は同時に解禁する。** 安定と不安定は2音ないと作れないため。
  1音しか使えない回を置くと「落ち着く音」を体験させられず、狙いと手段が噛み合わない。
  （2026-09-27に変更。以前は 1 → 5 → 3 → 2 の順で、ドリル1〜2は1度だけだった）
- **順次進行を跳躍より先に教える。** 1 → 5 → 3 の順だと Phase 1 で作れるのがアルペジオだけになり、
  「ポップスのコツ」の「基本は順次進行、跳躍はここぞで」と逆の順序を教えることになっていた
- **V はドリル1から使う。** V の上では1が4（11th）でぶつかるが、2が5thなので逃げ場になる。
  2を同時に解禁したことで、V回避のために5度を前倒しする理由がなくなった
- **4on5（IV/V）は初期に使わない。** 初学者には「ドミナント＝V」の像がぼやけ、
  ドを IV の5th と読むか V の11th と読むかで混乱するため。ドリル11で種明かしする
- **中間制作はドリル5。** ヨナ抜きがドリル4で完成するので、その直後に置く。
  続くドリル6〜7（コード回）で「自分のメロにコードを付け直す」につなげられる
- ブルーノート（♭3/♭7）はドリル12のモチーフ展開と抱き合わせ
- 「ポップスのコツ」はコード・音選び・形・リズムの4観点。
  言葉の観点は作詞をやらないので削除した。構成の観点も外した（2026-09-28）
- **コツのページ全体の鉄則は「繰り返さないと意味不明、繰り返しすぎるとおもんない」。** 冒頭文の下に大きく出す（以前はリズムの節の頭だった）
- **コードの観点は「普通のコードと変なコードを区別する」「ダイアトニックコードをグループ分けする」と、覚えるべきコードの tier 表。**
  どちらもコツのページの一番上に出す。tier 表にあるのが普通のコード、それ以外は変なコード、くらいの扱い。
  sus4 以外は全部4和音で書く。tier1＝IM7〜VIIm7-5 と Isus4・IVsus4・Vsus4／tier2＝III7・IVm7（次に引っ張る系と短調から借りる系から1つずつ）／
  tier3＝VI7 II7 I7 Vm7 #IVm7-5 #Idim7 #Vdim7 ♭II7（次に引っ張る系）・♭VIM7 ♭VII7（短調から借りる系）。
  ページには系統のラベルは出さない（「引っ張る」「借りる」は外した）。tier1 はグループ分けのコツの3グループで色分けする。
  #Vdim と #Idim は III7・VI7 の根音抜きとほぼ同じ音で、行き先も同じ。
  **tier2・3 をどの回の講義で扱うかは未定**（案：tier2＝ドリル7、tier3＝ドリル11）
- **「音楽理論ロードマップ」の原典は、DTM初級の講義スライド**
  `~/Library/CloudStorage/Dropbox/大学関連/2026/DTM初級/授業資料/DTM初級20260622.pptx`
  の p.20-61「何もわからないい人用の音楽理論ロードマップ」。
  **これは1Q/2QのDTM初級（月曜）の資料で、この授業のものではない。**
  内容は転用してよいが、出どころを取り違えないこと。
  4段階（トーナリティ→インターバル→メジャースケール→ダイアトニックコード）と、
  「音楽理論＝いいかんじの音楽あるある」「根幹＝中心からの距離で安定/不安定をコントロールする体系」
  「不安定＝安定したいという欲望」は原典の言葉。**勝手に段階を作り直さないこと。**
  授業の回への対応は各段階の末尾に小さく添えるだけにする
- **和音は135積みにしない。** ベースにルート、上は転回形の3声（4和音はルート抜きの3・5・7）。詳細は README の「和音のボイシング」（2026-09-28）
- 評価の比重（課題40/中間20/最終30/相互分析10）は仮置き。大学の成績基準に合わせて調整予定

## 文章の方針（学生が読む文すべて）

**「ポエムいらない、核だけ」。** 主張・事実・指示だけを短く言い切る。
説明のための描写、資料やページについての説明、何でも「ラベル：本文」に並べる書き方は「AI臭い」「きもい」と突き返された（2026-09-28）。
見本は有村さん自身の文：
- 「ポップスとは、真ん中（トーナルセンター）からの距離でデザインする音楽。だから、キーの理解が全ての出発点になる。」
- 「ポップスの作曲コツ集。あくまでコツであってルールではない。」

名詞止めでよい。書き直すときは元より短くする。有村さんが書いた見出し・文は言い換えない。
